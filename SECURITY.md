# Security

To report a security problem in either extension, use
[a private security advisory](https://github.com/mfclay/azure-devops-extensions/security/advisories/new)
rather than a public issue. Only the maintainer can read it. Say which extension and version,
and what an attacker could do.

Expect a first reply within a week. Fixes ship as a new extension version, which Azure DevOps
installs automatically.
